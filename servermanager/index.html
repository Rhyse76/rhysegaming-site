RhyseGaming Server Manager

A clean, modern, all-in-one desktop app for running your own Palworld, ARK: Survival Ascended, or Enshrouded dedicated server — install, configure, monitor, back up, and automate it, all from one window.

Why I built this

Running a dedicated server shouldn't mean hand-editing giant config files, hunting for SteamCMD commands, and babysitting crashes. I tried the existing tools for Palworld, ARK, and Enshrouded — most are abandoned, clunky, single-game, or have broken features — so I built the manager I actually wanted to use, and kept adding games to it.

The goal is simple: everything you need to run a healthy server in one clean, fast app, whichever of the three games you're hosting. Point-and-click install, a real settings editor, live dashboards where the game supports them, automatic backups, and a crash watchdog that quietly restarts your server if it falls over. It's free, and it's built by someone who runs game servers too.

Everything in one place

No more spreadsheets of commands or half-broken panels.

Palworld, ARK: SA & Enshrouded

One app, three games — pick a game per server profile and the manager adapts its config, mods, and live control to fit.

Install & auto-update

Bootstraps SteamCMD and installs the server for you — plus auto-detects and gracefully applies new game versions.

Full config editor

Every setting for your game — Palworld's OptionSettings, ARK's GameUserSettings/Game.ini, or Enshrouded's JSON — as friendly toggles and inputs, with search.

Live dashboard

Who's online, server FPS/uptime with live graphs, broadcast, and kick / ban / unban in real time — for Palworld (REST) and ARK: SA (RCON).

Backups & off-site copy

One-click world snapshots and restore — and mirror every backup to a cloud-synced folder for off-site safety.

Automation

Scheduled restarts (smart: wait until empty), scheduled backups, a crash watchdog, and recurring announcements.

Discord notifications

Post server up/down/crash, player join/leave, and backup events straight to your Discord channel.

Connectivity helper

Shows your public connect address and opens the game port automatically via UPnP — the "my friends can't join" fix.

Mod manager

Install and manage Palworld .pak mods or search and add ARK's CurseForge mods — no digging through folders.

Multi-server profiles

Manage several servers, even across different games, and switch between them instantly.
