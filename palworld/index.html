Palworld Server Manager

A clean, modern, all-in-one desktop app for running your own Palworld dedicated server — install, configure, monitor, back up, and automate it, all from one window.

Why I built this

Running a Palworld dedicated server shouldn't mean hand-editing giant config files, hunting for SteamCMD commands, and babysitting crashes. I tried the existing tools — most are abandoned, clunky, or have broken features — so I built the manager I actually wanted to use.

The goal is simple: everything you need to run a healthy server in one clean, fast app. Point-and-click install, a real settings editor, a live dashboard, automatic backups, and a crash watchdog that quietly restarts your server if it falls over. It's free, and it's built by someone who runs game servers too.

Everything in one place

No more spreadsheets of commands or half-broken panels.

One-click install & update

Bootstraps SteamCMD and installs or updates the dedicated server for you — with a live progress bar.

Full config editor

Every setting from PalWorldSettings.ini — difficulty, rates, PvP, player caps — as friendly toggles and inputs, with search.

Live dashboard

See who's online, server FPS and uptime, broadcast messages, and kick or ban players in real time.

Backups & restore

Snapshot your whole world with one click, and restore any backup when things go sideways.

Automation + crash watchdog

Scheduled restarts and backups, plus automatic recovery that restarts the server if it ever crashes.

Multi-server profiles

Manage several servers and switch between them instantly — each with its own location and settings.
